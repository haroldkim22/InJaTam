# 부여 부소산 인근 파노라마 소리 지도

> 2025 인문자연탐사 프로젝트

---

**탐사 장소**: 부소산 및 부소산 인근 지역 (구드래 조각공원, 삼정관광호텔, 관북리 유적 등).


## 주요 기능

### 1. 지도 기본 기능 및 장소 마커

* 지형도
* 지도 상의 각 장소 마커를 클릭하여 해당 위치의 360도 VR 사진과 현장 음성 확인


### 2. 파노라마 팝업 뷰어

* **360도 이미지**: 마커 클릭 시 360도 사진이 팝업 창으로 나타남
  마우스 드래그를 통해 시점 전환 및 확대/축소가 가능
  모바일 기기에서는 자이로스코프 센서 기능을 활용한 화면 전환 지원

* **현장 소리 재생**: 해당 위치에서 녹음된 소리가 약 1분간 재생
  볼륨 및 재생 속도 조절 가능



### 3. 사용자 커스텀 마커 추가

* 사용자가 직접 지도 상의 특정 위치를 마우스로 선택하여 새로운 마커를 생성할 수 있음
* 입력 사항
  1. 마커 이름
  2. 사진 및 소리 파일 URL
  3. 장소에 어울리는 태그 입력


### 4. 검색 및 데이터 관리
* **태그 필터링**: 사용자가 선택한 키워드(태그)를 모두 포함하는 장소의 마커만 지도 위에 필터링하여 보여줌

* **모든 태그 표시**: 등록된 모든 마커의 이름과 태그 정보를 한눈에 파악할 수 있도록 표로 제공

* **마커 데이터 저장**: 웹브라우저에서 사용자가 새롭게 추가한 마커의 정보 목록을 `txt` 파일로 내보낼 수 있음

## 🛠️ 데이터 수집 및 처리 프로세스

1. **현장 탐사 및 촬영**: 카메라의 파노라마 기능을 사용하여 부소산 인근 총 35개의 지점에서 주변 환경 촬영


2. **녹음**: 각 촬영 지점에서 약 1분 동안 주변 소리 녹음


3. **위치 기록**: 지도 앱을 활용하여 데이터가 수집된 지점들의 위치 기록


4. **인물 지우기**: 초상권 침해 방지 밒 몰입감 향상을 위해 AI 지우개 툴을 이용해 촬영된 사진 속 행인들 제거


5. **360도 이미지 변환**: 파노라마 평면 이미지를 `Photosphere Converter` 및 `Pano to 360`를 사용해 360도 이미지 포맷으로 변환


6. **오디오 노이즈 제거**: 소리 녹음본에서 잡음 제거


7. **최종 통합**: 가공 완료된 이미지 파일과 오디오 파일, 위치 정보를 매칭하여 데이터베이스에 저장
